# Teeworlds с ботами — Docker / Portainer

Это форк [официального Teeworlds](https://github.com/teeworlds/teeworlds), в который перенесены боты из [nheir/teeworlds (server_bot0.7)](https://github.com/nheir/teeworlds/tree/server_bot0.7). Основа — актуальная upstream-ветка `master` на дату интеграции, а не устаревшая копия 0.7.5. Движок и сетевые исправления остаются из официального проекта. Клиент 0.7.x изменять не нужно.

## Portainer

Откройте **Stacks → Add stack → Web editor** и вставьте [compose.yaml](compose.yaml). Укажите порт UDP 8303 на хосте и нажмите Deploy.

Образ: `ghcr.io/mirivlad/teeworlds-bots:latest`.

Он публикуется GitHub Actions в GHCR после обновления ветки `master`. Первая публикация должна завершиться успешно до установки стека.

Официальные карты **уже входят в образ**, дополнительные загрузки не нужны: они поставляются как Git-подмодуль `datasrc/maps` от `teeworlds/teeworlds-maps`, а сборка переносит их в каталог `data/maps` контейнера. Для публикации используется `actions/checkout` с `submodules: recursive`.

### Настройки

Меняйте переменные `environment` в compose-файле и обновляйте стек:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `TW_SERVER_NAME` | Teeworlds Bots | Имя сервера |
| `TW_MAP` | dm1 | Официальная карта |
| `TW_MAP_ROTATION` | all | Все карты, входящие в образ, по очереди; пустое значение отключает ротацию |
| `TW_VOTE_MAPS` | all | Все карты в меню голосования; пустое значение отключает варианты голосования |
| `TW_MATCHES_PER_MAP` | 1 | Сколько матчей играть на одной карте до следующей |
| `TW_TIME_LIMIT` | 0 | Продолжительность матча в минутах; 0 — без ограничения времени |
| `TW_SCORE_LIMIT` | 20 | Лимит очков на матч; 0 — без ограничения |
| `TW_GAME_TYPE` | dm | dm / tdm / ctf |
| `TW_MAX_CLIENTS` | 16 | Всего мест на сервере |
| `TW_PLAYER_SLOTS` | 12 | Игровые слоты |
| `TW_BOT_SLOTS` | 4 | Число ботов (освобождают место для людей) |
| `TW_BOT_DIFFICULTY` | normal | `novice`, `normal`, `veteran` (или 0/1/2) |
| `TW_BOT_ALWAYS_ENABLE` | 2 | 0 — только с игроками; 1 — существуют без игроков; 2 — играют без игроков |
| `TW_BOT_ALLOW_MOVE` | 1 | Разрешить движение |
| `TW_BOT_ALLOW_FIRE` | 1 | Разрешить стрельбу |
| `TW_BOT_ALLOW_HOOK` | 1 | Разрешить крюк |
| `TW_PUBLIC` | 0 | 0 — частный тестовый сервер; 1 — регистрация в master server |
| `TW_RCON_PASSWORD` | пусто | Пароль RCON — лучше задать явный сильный пароль |

После запуска подключайтесь клиентом Teeworlds 0.7.x к IP сервера, порт **8303/UDP**. Для игры через интернет откройте входящий UDP 8303 в firewall/роутере.

### Уровни сложности ботов

Установите `TW_BOT_DIFFICULTY` в Portainer и выполните обновление стека:

- `novice` (0): задержка реакции около 650 мс, неточная стрельба (до 15° отклонения), пауза между попытками выстрела около 450 мс; крюком пользуется осторожнее.
- `normal` (1, по умолчанию): задержка реакции около 300 мс, отклонение прицеливания до 7°, пауза между попытками выстрела около 220 мс.
- `veteran` (2): задержка реакции около 80 мс, отклонение прицеливания до 1,5°, пауза между попытками выстрела около 70 мс; активнее применяет крюк.

Это предельные интервалы решений бота, а не гарантия частоты выстрелов: оружие по-прежнему подчиняется игровому времени перезарядки. Навигация и маршрутная логика одинаковы на всех сложностях. `TW_BOT_ACCURACY: "0"` отключает случайный разброс прицеливания на любом уровне (обычно это не нужно).

В пользовательском `/config/server.cfg` используйте серверный параметр `sv_bot_difficulty 0|1|2`. Если пользовательский файл существует, переменные окружения `TW_*` имеют более низкий приоритет.

### Смена карт во время игры

Если настроить `TW_RCON_PASSWORD` в стеке, в клиенте Teeworlds можно подключиться к серверу, нажать **F2**, войти с паролем RCON и выполнить:

```text
change_map dm2
```

Это меняет карту без перезапуска контейнера. По умолчанию `TW_MAP_ROTATION: "all"` и `TW_VOTE_MAPS: "all"`: все карты из `data/maps` автоматически участвуют и в ротации, и в голосовании. `TW_MATCHES_PER_MAP: "1"` меняет карту после каждого матча. Пустое значение `TW_MAP_ROTATION` отключает ротацию, пустое `TW_VOTE_MAPS` — варианты голосования. При желании вместо `all` можно указать отдельные имена карт через пробел. Учтите: ротация и голосования меняют карту, но не `sv_gametype`. При `TW_GAME_TYPE: "dm"` CTF- и LMS-карты тоже будут загружены как карты для DM; для полноценного CTF/LMS необходимо сменить и режим игры. В стек также вынесены лимит времени (`TW_TIME_LIMIT`) и очков (`TW_SCORE_LIMIT`), чтобы матчи завершались предсказуемо.

### Пользовательский конфиг

Если нужен полный контроль параметров, создайте `/config/server.cfg` в именованном томе `teeworlds-config`. При его наличии контейнер копирует его в пользовательский каталог хранения игры и запускает с ним сервер, игнорируя переменные `TW_*`. При отсутствии этого файла параметры `TW_*` записываются в `/config/data/teeworlds/.generated-server.cfg` при каждом запуске.

### Локальная сборка

```bash
git clone --recursive https://github.com/mirivlad/teeworlds.git
cd teeworlds
docker build -t teeworlds-bots:local .
docker compose -f compose.yaml up -d
```

В примере compose используется GHCR-образ. Для запуска именно локальной сборки замените поле `image:` на `teeworlds-bots:local`.

### Статус

- Проверено: сборка сервера Linux amd64, карта dm1, 4 бота двигаются, подбирают предметы и сражаются.
